## ✨ Features & Architecture

- **Neon Cyber / Web3 Aesthetic:** Dark space canvas (`#040711`), neon cyan (`#00F0FF`), electric purple (`#A855F7`), and emerald accents with smooth glassmorphism and subtle cyber-grid backdrop.
- **Bilingual (English ⇄ Persian):** Instant locale switching with custom `LanguageContext`. Supports dynamic text alignment and Persian typography (**Vazirmatn**) with zero letter-spacing distortions.
- **Career & Collaboration Modes:** Dedicated sections detailing preferences for **Freelance**, **Remote**, and **Hybrid** work.
- **Interactive Project Showcase:** Filterable gallery displaying production web applications with live links, tech tags, and architectural highlights.
- **Embedded Resume (PDF):** Real-time downloadable PDF resume accessible via Navbar, Hero, and Contact sections.
- **Direct Contact Launcher:** Integrated form generating pre-formatted client inquiries and one-click clipboard copying.

## 💻 Local Development

Clone the repository and install dependencies:

```bash
git clone https://github.com/Sajjaddi/portfolio.git
cd portfolio
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

Build for production:

```bash
npm run build
```
